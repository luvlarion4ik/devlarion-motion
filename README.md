# Devlarion Motion

Экспериментальная версия сайта студии Devlarion: тот же контент, что и на [основном сайте](https://luvlarion4ik.github.io/luvlarion4ik/), но в «кинематографичной» подаче.

**Сайт:** https://luvlarion4ik.github.io/devlarion-motion/ · [English](https://luvlarion4ik.github.io/devlarion-motion/en/)

## Что внутри

- **Облако частиц на WebGL** (`docs/assets/field.js`, без зависимостей). Каждая секция задаёт свою сцену, и при прокрутке десятки тысяч точек перелетают из фигуры в фигуру:
  знак Devlarion с орбитами → «литник» с иконками услуг → машина из точек → сфера процесса → галактика продуктов → волна → ночная дорога.
- **Машина едет за курсором.** Луч от мыши пересекается с плоскостью земли, машина поворачивает в сторону движения и распыляет искры. Клик по фону даёт залп.
- Точки расступаются вокруг курсора, камера плавно реагирует на мышь и прокрутку.
- Цвет логотипа и акцентов меняется от секции к секции. Объёмный wordmark наклоняется за мышью.
- Клавиатурная навигация: `1`–`6` — разделы, `↓`/`↑` (или `J`/`K`) — следующая и предыдущая секция, `T` — Telegram, `L` — язык.
- Стеклянные панели с бликом за курсором, вкладки услуг, анимированные иконки, вращающиеся стикеры, «командная строка» с выбором канала связи и копированием.
- При `prefers-reduced-motion` анимации отключаются, без WebGL остаётся градиентный фон.

## Сборка

Нужен Node.js 22, дополнительные пакеты не требуются.

```bash
npm run build   # собрать docs/index.html и docs/en/index.html из content/
npm run serve   # локальный просмотр на http://127.0.0.1:4180
```

Тексты, кейсы, продукты и цены берутся из `content/` — это копия данных основного репозитория [luvlarion4ik/luvlarion4ik](https://github.com/luvlarion4ik/luvlarion4ik). Калькулятор, кабинет и подробные страницы кейсов остаются на основном сайте, новая версия ссылается на них.

GitHub Pages публикует папку `docs/` из ветки `main`.
