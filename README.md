# Devlarion Motion

Экспериментальная версия сайта студии Devlarion: тот же контент, что и на [основном сайте](https://luvlarion4ik.github.io/luvlarion4ik/), но в «кинематографичной» подаче.

**Сайт:** https://luvlarion4ik.github.io/devlarion-motion/ · [English](https://luvlarion4ik.github.io/devlarion-motion/en/)

## Что внутри

- **Облако частиц на WebGL** (`docs/assets/field.js`, без зависимостей). Каждая секция задаёт свою сцену, и при прокрутке десятки тысяч точек перелетают из фигуры в фигуру:
  знак Devlarion с орбитами → «литник» с иконками услуг → седан на подиуме → экраны проектов → галактика продуктов → сфера процесса → волна → ночная дорога. Клик по фону рядом с машиной даёт сноп искр.
- Точки расступаются вокруг курсора, камера плавно реагирует на мышь и прокрутку.
- Седан представительского класса из точек: на подиуме поворачивается за курсором, в финале едет по ночной дороге и перестраивается влево-вправо.
- Знак Devlarion с собственной анимацией: контур прорисовывается, проявляется заливка, прорезается L, проходит блик; на 404 знак разворачивается вокруг стойки D. Иконки со старого сайта (Animateicons), моноширинные подписи JetBrains Mono (OFL). В разделе «О студии» знак собирается по мере прокрутки, при наведении проигрывается заново. Threads в шапке, на первом экране и в контактах.
- Переключатель RU/EN, выбор валюты цен и калькулятор стоимости с отправкой расчёта в Telegram.
- Курсы Банка России: `npm run rates` забирает официальный XML ЦБ в `docs/assets/rates.json`, GitHub Action обновляет его по будням. Если файл устарел, браузер берёт свежие курсы ЦБ через зеркало cbr-xml-daily.ru.
- Своя страница 404.
- Цвет логотипа и акцентов меняется от секции к секции. Объёмный wordmark наклоняется за мышью.
- Клавиатурная навигация: `1`–`7` — разделы, `↓`/`↑` (или `J`/`K`) — следующая и предыдущая секция, `T` — Telegram, `L` — язык.
- Стеклянные панели с бликом за курсором, вкладки услуг, анимированные иконки, вращающиеся стикеры, «командная строка» с выбором канала связи и копированием.
- При `prefers-reduced-motion` анимации отключаются, без WebGL остаётся градиентный фон.

## Сборка

Нужен Node.js 22, дополнительные пакеты не требуются.

```bash
npm run build   # собрать docs/index.html и docs/en/index.html из content/
npm run serve   # локальный просмотр на http://127.0.0.1:4180
npm run rates   # обновить курсы ЦБ
```

Тексты, кейсы, продукты и цены берутся из `content/` — это копия данных основного репозитория [luvlarion4ik/luvlarion4ik](https://github.com/luvlarion4ik/luvlarion4ik). Кабинет и подробные разборы кейсов остаются на основном сайте, новая версия ссылается на них.

GitHub Pages публикует папку `docs/` из ветки `main`.
